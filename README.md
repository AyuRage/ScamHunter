## 📖 О проекте

**AyuScamDB** — независимый проект с открытым исходным кодом, посвящённый обнаружению, исследованию и разоблачению интернет-мошенничества, фишинговых кампаний и мошеннических веб-ресурсов.

Наша миссия — сделать интернет безопаснее посредством открытых исследований и информирования пользователей о существующих угрозах.

## 🎯 Цели проекта

- 🔍 Исследование подозрительных веб-сайтов.
- 🛡️ Обнаружение и документирование фишинговых кампаний.
- 🗃️ Ведение открытой базы интернет-угроз.
- 🚨 Разоблачение мошеннических платёжных систем.
- 🏛️ Выявление поддельных государственных ресурсов.
- 📡 Исследование открытых источников информации (OSINT).
- 📚 Повышение цифровой грамотности пользователей.

## 🔬 Последнее расследование

### AYU-0001 — Поддельный государственный браузерный блокировщик

**Дата обнаружения:** 21 ноября 2026 года.

**Предполагаемые целевые страны:** Украина, Казахстан, Россия.

**Обнаруженные особенности:**

- Использование символики государственных органов.
- Поддельные административные штрафы.
- Имитация интерфейса браузера и операционной системы.
- Имитация шифрования AES-256.
- Психологическое давление на пользователя.
- Требование срочной оплаты.
- QR-коды, ведущие на подозрительные платёжные страницы.

**Классификация:** Browser Locker / Scareware / Предполагаемый фишинг.

Фактическое заражение системы или шифрование файлов не подтверждено.

Данный репозиторий предназначен исключительно для образовательных целей, защитных исследований и противодействия интернет-мошенничеству.
